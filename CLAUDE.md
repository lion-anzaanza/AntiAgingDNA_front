# lifeDNA (AntiAgingDNA_front)

Expo / React Native app whose UI is ported from Figma. **Figma is the source of
truth and is still changing — re-pull the node before implementing or "fixing"
any screen, and never treat the existing code as a record of what the design
says.**

Both files below are imported, so they are always in context: the first tells
you what exists, the second tells you how to work on it without repeating
mistakes that have already cost a bug each.
